# Portfolio Web Developer

Website portfolio pribadi Zahra Nailul Aisyah dengan desain modern dan tema ungu.

## Tentang Saya
Saya adalah siswi kelas 10 Rekayasa Perangkat Lunak yang sedang mempelajari pengembangan website, khususnya Front-End Development.

## Keahlian dan Kompetensi
- HTML5 Semantic
- CSS3 Flexbox
- Responsive Design
- Media Queries
- Chrome DevTools
- Git & GitHub

## Fitur Website
- Kartu profil dengan avatar
- Deskripsi singkat tentang diri
- Daftar keahlian dalam bentuk badge
- Tombol Kirim Pesan
- Desain dark mode dengan aksen ungu

## Teknologi
- HTML5
- CSS3
- JavaScript (jika digunakan)

## Cara Menjalankan
1. Buka repository di Visual Studio Code.
2. Jalankan file index.html melalui browser.
3. Gunakan Live Server untuk melihat perubahan secara langsung.
